\section*{Выводы по аналитическому разделу}
\addcontentsline{toc}{section}{Выводы по аналитическому разделу}

В разделе формализованы объекты сцены и ограничения на входные данные и проведено сравнение методов по количественным критериям. Были выбраны следующие алгоритмы:
\begin{itemize}
	\item модель освещения Блинна "--- Фонга без фоновой составляющей;
	\item метод теневого z-буфера для теней от источника света на бесконечности и от свечения сияния;
	\item шум Перлина для синтеза основания занавеса и изменения его формы и яркости во времени;
	\item трассировка лучей в светящейся среде с пошаговым интегрированием излучения и поглощения по расчётной сетке;
	\item замена свечения каждого занавеса набором точечных источников для освещения сцены.
\end{itemize}
