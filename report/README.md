# РПЗ

Каркас записки: преамбула, титульный лист, заглушка листа задания, содержание и список источников. Файлы разделов в `parts/` (`03-introduction` … `08-conclusion`) и `parts/bibliography.bib` пока пустые. В `report.tex` титул, задание и ещё не начатые разделы закомментированы, раскомментировать по мере готовности. Лист задания (`parts/01-task.tex`) — заглушка под официальный бланк: PDF бланка положить в `img/task.pdf`.

## Оформление временное

- **Преамбула** (`preamble.tex`) скопирована из лабы по АА:
  `lab-works/sem_5/AA/lab_01/report/preambula.tex`, версия от 28.09. Скорее всего поменяется. Отличия от лабы помечены в файле комментарием `курсовая:`.
- **Титульный лист** (`parts/01-title.tex`) собран по образцу лабы и, скорее всего, будет заменён официальным бланком. Заполнить:
  - ФИО руководителя (сейчас «И.О. Фамилия»);
  - точную формулировку темы из утверждённого задания.
- **Стиль списка источников** — `ugost2008-utf8.bst`, копия `ugost2008.bst` из TeX Live с двумя исправлениями:
  - под XeLaTeX исходный стиль печатает «с.» в числе страниц русских книг как «Ñ�», в копии это исправлено;
  - `\endinput` в конце файла BibTeX считает ошибкой, из-за чего `latexmk` прерывает сборку, поэтому он убран.

## Сборка

```bash
latexmk -xelatex report.tex
```

Texpad тоже подойдёт. Нужны XeLaTeX и шрифты Times New Roman и Menlo (на macOS есть). Пока в тексте нет ни одной ссылки на источник, BibTeX сообщает об ошибке — это ожидаемо, PDF всё равно собирается.
