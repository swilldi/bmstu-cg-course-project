# Северное сияние — курсовая работа по компьютерной графике (МГТУ)

macOS-приложение, которое в реальном времени строит и рендерит 3D-сцену: заснеженный
горный ландшафт, минимум пять объектов на нём, направленный источник света с тенями —
и над всем этим процедурно генерируемое северное сияние, форма и яркость которого
меняются во времени по параметрам, задаваемым пользователем через GUI.

Статус: 📝 заготовка готова, реализация не начата.

## Где что лежит

| Файл | Для кого | Что внутри |
|---|---|---|
| `README.md` | для меня | этот файл — общая картина и как запустить |
| `CLAUDE.md` | для агента | роль агента, целевой результат, обязательные паттерны и ограничения ТЗ |
| `docs/SPEC.md` | для обоих | полный текст ТЗ, разбивка на требования, явные уточнения и то, что не делаем |
| `docs/ARCHITECTURE.md` | для обоих | модули, протокол смены метода синтеза сияния, модель освещения и рендера |
| `docs/PLAN.md` | для обоих | чек-лист по этапам курсовой (анализ → проектирование → технологический → исследование → защита), с 🤖-метками |
| `docs/REVIEW.md` | для агента | чек-лист ревью: соответствие ТЗ, архитектурная граница, код-стиль |
| `docs/NOTES.md` | для меня | кандидаты методов синтеза для сравнительной таблицы, открытые вопросы, решения |

Стека отдельно нет — он уже зафиксирован проектом: Swift + SwiftUI (GUI) + SceneKit
(сцена/камера/меши) + Metal/MSL (весь свой шейдинг и вычисления: освещение, сетка и
объёмный рендер сияния), только
macOS. Почему сторонних библиотек не нужно — одной строкой в
[SPEC.md](docs/SPEC.md#средства-реализации).

Отдельно важно: руководитель требует баланс движок/вручную (не всё через SceneKit, не всё
руками) — таблица, что где, в [ARCHITECTURE.md](docs/ARCHITECTURE.md#кто-что-делает).

## Как открыть

```bash
open NortherLights/NortherLights.xcodeproj
```

Таргет — macOS (нужен Mac с поддержкой Metal). Схема сборки и запуска — стандартная,
Cmd+R.

## Откуда взялось ТЗ

Формулировка задания — `../КР_КГ_ПримерПроцессаРазработкиПО.pdf` в родительской папке
описывает не тему, а сам процесс выполнения курсовой (5 этапов + защита, что должно
попасть в РПЗ и в презентацию на каждом этапе). [PLAN.md](docs/PLAN.md) — это ТЗ пособия,
разложенное на конкретные шаги под тему сияния. Даты на диаграмме Ганта в пособии —
формальность, единственная жёсткая точка — защита на 15–17 неделе.

## Роль агента

Агент — только ревью кода по чек-листу и явно запрошенные повторяющиеся правки без
собственных архитектурных решений. Код пишу сам. Подробности — [CLAUDE.md](CLAUDE.md).
